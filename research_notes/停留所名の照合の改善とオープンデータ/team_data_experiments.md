# チームのデータでの確認と実験（2026-11-16、コーディネーターが実施）

このノートは Web の調査ではなく、ハッカソンのデータ（10月の乗車券・GPS・GTFS v32）とチームのコードで、コーディネーター自身が計算した結果。報告書では【データ確認】【実験】として扱う。スクリプトはリポジトリの `experiments/ticket_gps/`（出力の `out/` は元データ由来の名前を含むのでコミットしない）。

## 1. 乗客は乗ってから買うか（車両番号つきの券を、同じ車両の GPS と突き合わせる）

`experiments/ticket_gps/purchase_timing.py`、10/13〜16、車両番号つきで両端が名前の完全一致で対応した券 111,955 枚。

- 券の `vehicle_number` の車両が同じ日の GPS にいる: 99.1%。同じ日に券と同じ路線を走っている: 95.5%。→ 券の車両番号は GPS の `vehicle_id` とそのまま結合できる。
- A. 購入時刻 − その車両が乗車停留所（券の路線の乗車 seq）を通った時刻（60m 以内の最近点、±90分で最も近い通過）。通過を検出できた 77,633 枚（69.3%）:
  - 中央値 +0.8 分（四分位 +0.1〜+1.3 分）
  - 通過の2分より前 6.3% / 0〜2分前 16.1% / 0〜2分後 65.4% / 2〜5分後 9.5% / 5〜15分後 2.0% / 15分より後 0.7%
  - 起点（seq=0）で乗った券は中央値 +1.4 分で、ばらつきが大きい（起点での待機のため）
- B. 購入の瞬間（直前60秒以内の GPS の点）のバスの位置を、券の路線の最寄りの停留所に当てる。位置が取れた 96,801 枚（そのとき GPS 上も同じ路線 95.3%、路線の停留所から300m以内 85.9%）:
  - 最寄りの停留所が 乗車停留所 66.6% / 1つ先 22.0% / 2つ先 2.4% / 3つ以上先 1.3% / まだ手前 7.7%
- 解釈: 大半は乗った直後、バスが乗車停留所か次の停留所までの間にいるうちに買う。販売側の券は翌日3時まで有効で停留所で先に買うこともできるが、実際には少ない。

## 2. GPS による検出の取りこぼし（問題1の土台）

10/15、全路線。確実にその停留所を通った便（前と後の停留所で通過を検出した便）のうち、その停留所でも通過を検出できた割合:
- 全体 77.3%。路線×停留所（5便以上）50,265 組の中央値 83%、50%未満 9.7%、70%未満 25.1%、90%以上 31.1%。

## 3. GPS で停留所名を推定する（別名の学習と、今の照合の点検）

`experiments/ticket_gps/alias_from_gps.py`、10/1〜31。車両番号つきで購入時のバスの位置が取れた券 956,313 枚（直前60秒以内の GPS の点が、券の路線の停留所から300m以内）。今の照合（`src/tsh/crowding.py` の `match_stops`）を端ごとに再現すると、これらの券の乗車名は 完全一致 71.9%・あいまい一致 14.6%・距離での退避 3.2%・照合できず 10.2%。

方法（名前の文字列を見ない）:
1. ずれの分布 P(k)。k = 購入時のバスの最寄りの停留所の seq − 乗車停留所の seq。名前が完全一致で路線上の1か所に決まる券で数えた: k=0 65.1%、+1 23.0%、−1 5.5%、+2 2.4%、−2 1.3%、そのほか各1%未満。
2. 投票。（路線方向, 乗車名）ごとに、路線の各停留所 s の点数 = Σ_券 P(最寄りの seq − s)。首位を推定とし、「差」=（首位の点数 − 2位の点数）/ 券の枚数 を確からしさとする（途中の停留所なら最大でおよそ 0.65−0.23=0.42）。

結果:
- **名前を隠して当てる（完全一致の名前を正解に使う）**: （路線, 名前）の組ごとの当たり（同じ停留所）／±1停留所
  - 1枚以上 33,693 組: 77.4% ／ 95.8%（券の枚数で重みを付けると 91.2%）
  - 10枚以上 13,099 組: 89.3% ／ 98.9%（重み 93.0%）
  - 50枚以上 3,100 組: 94.3% ／ 99.2%
  - 10枚以上で差0.2以上 8,249 組: 96.8% ／ 99.7%。差0.3以上 4,917 組: **97.8%** ／ 99.8%
  - 起点・終点の停留所は当たりにくい（10枚以上で 83.5%、途中は 89.5%）。起点での待機中に買うため
- **今の照合の点検**（10枚以上・差0.3以上の組で、今の照合の停留所と GPS の推定が同じか）:
  - 完全一致 4,936 組: 一致 97.8%（±1停留所 99.8%）
  - あいまい一致 969 組: 一致 **83.6%**（±1停留所 92.3%、券の枚数で重み 89.4%）
  - 距離での退避 213 組: 一致 85.0%（±1停留所 99.1%）

- 限界: 正解率は「完全一致の名前」で測ったもので、照合できない名前（印のない路線に多い）でも同じとは限らない。車両番号つきの券に十分な枚数がある（路線, 名前）にしか使えない。ずれの分布は全路線で1つ（停留所の間隔や混雑で変わりうる）。学んだ別名は人の確認と版の記録をしてから使う。外部のデータは一切使っていない。
